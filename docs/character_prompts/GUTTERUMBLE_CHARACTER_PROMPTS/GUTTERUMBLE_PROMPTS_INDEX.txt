HOW TO USE THESE PROMPTS:
-------------------------

OPTION A: Generate with Hugging Face SDXL/FLUX directly
1. Copy entire prompt text (e.g., RATS_GRUNT_01 "Brick")
2. Paste into Hugging Face Spaces SDXL or FLUX
3. Adjust generation settings:
   - Quality: "Professional 3D game character concept art"
   - Seed: Vary per gang to maintain cohesion
   - Negative: "blurry, low quality, multiple people, anime, photorealistic"
4. Generate at 768x1024 (portrait orientation for character sheets)

OPTION B: Use with Claude Image Generation (if available)
1. Create batch request with multiple prompts
2. Reference specific gang for cohesion (e.g., "Generate RATS gang grunts")
3. Regenerate if variance is insufficient (skin tone, body type)

OPTION C: Adapt for AI Art Tools (Midjourney, Ideogram, etc.)
1. Copy prompt text
2. Adjust format to tool-specific syntax (Midjourney uses "--" parameters)
3. Add style reference: "--style raw --ar 3:4 --niji"
4. Maintain core descriptors (ethnicity, body type, gang color)
