# Store Listing & Staged Rollout (Phase 7)

Manual steps — requires Play Console access.

## 7.1 — Store listing assets

- [ ] Screenshots (phone + 7" tablet)
- [ ] Feature graphic (1024×500)
- [ ] Short description (80 chars)
- [ ] Full description
- [ ] Preview listing on phone and tablet layouts in Play Console

## 7.2 — Staged rollout

- [ ] Upload AAB to production track at 5–10% rollout
- [ ] Monitor crash rate and ANR for 48–72 hours
- [ ] Increase rollout percentage if healthy
- [ ] Reach 100% only after stability bar met (see Phase 6.3)
